## 📱 Project Overview

The **Smart Safety Alert System** is a mobile application developed as a **Final Year Project (FYP)**. It helps users quickly report incidents, send SOS alerts, share their live location, and receive AI-powered safety recommendations.

The application also includes a powerful **Admin Dashboard** for monitoring reports, users, alerts, and system analytics.

# 🧠 Guardian AI

Guardian AI analyzes each incident report and automatically classifies it into:

- 🟢 Low Risk
- 🟠 Medium Risk
- 🔴 High Risk

It also provides personalized safety recommendations based on the reported incident.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/hafsacodes/Smart-Safety-Alert-System.git
```

## Open Project

```bash
cd Smart-Safety-Alert-System
```

## Install Packages

```bash
flutter pub get
```

## Run Application

```bash
flutter run
```
